Reference

Enough to wire up create + status-check without leaving this page. Only shows the modes you've actually enabled above.

Create POST https://pay.cncportal.io/v1/payments?key=pk_live_51NcAurorify9f2c
Request body — what the widget sends when checkout starts
{ "amount": "128.77", "token": "USDC", "mode": "instant", "reference": "order_8842" }
Response — the id everything below is keyed on, your reference echoed back
{ "id": "pay_8f2c1a9e", "reference": "order_8842", "status": "pending", "amount": "128.77", "mode": "instant" }
Recheck GET https://pay.cncportal.io/v1/payments/{id}?key=pk_live_51NcAurorify9f2c
Response — same shape, status now reflects reality
{ "id": "pay_8f2c1a9e", "reference": "order_8842", "status": "paid", "amount": "128.77", "token": "USDC", "mode": "instant", "tx": "0x4f2a…c91b" }
